# User Management App 

PL: **User Management App** to aplikacja webowa stworzona za pomocą React i Redux (z wykorzystaniem Redux Toolkit), która umożliwia zarządzanie informacjami o użytkownikach. Aplikacja pobiera dane z publicznego API i pozwala na filtrowanie tych danych według kilku kryteriów.

**Funkcje:**
* Wyświetlanie listy użytkowników (imię, nazwisko, email, numer telefonu) pobranej z API (JSONPlaceholder).
* Możliwość filtrowania użytkowników według imienia, nazwy użytkownika, emaila oraz numeru telefonu.
* Dynamiczne aktualizowanie listy w miarę wpisywania danych w pola filtrowania.
* Zastosowanie Redux do zarządzania stanem aplikacji.
* Responsywny układ – strona dostosowuje się do różnych rozmiarów ekranu.

**Technologie:**
* React – do budowy interfejsu użytkownika.
* Redux + Redux Toolkit – do zarządzania stanem aplikacji.
* TypeScript – zapewnienie bezpieczeństwa typów w całej aplikacji.
* Material-UI (MUI) – do stylowania interfejsu użytkownika i komponentów.
* JSONPlaceholder API – do pobierania danych o użytkownikach.

ENG: **User Management App** is a web application built using React and Redux (with Redux Toolkit) that allows for managing user information. The application fetches data from a public API and enables filtering that data based on multiple criteria.

**Features:**
* Display a list of users (name, surname, email, phone number) fetched from an API (JSONPlaceholder).
* Filter users by name, username, email, or phone number.
* Dynamically update the list as data is entered into the filter fields.
* Use Redux for state management.
* Responsive design – the application adjusts to different screen sizes.

**Technologies:**
* React – for building the user interface.
* Redux + Redux Toolkit – for managing the application's state.
* TypeScript – to ensure type safety throughout the application.
* Material-UI (MUI) – for styling the user interface and components.
* JSONPlaceholder API – for fetching user data.
